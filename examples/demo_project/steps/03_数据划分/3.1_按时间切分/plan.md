# 3.1 按时间切分 · 计划

## 本步结束后要知道什么

模型用哪些月份学、哪些月份比较方法、哪些月份只在最后评估一次，保证评估时用不到未来的数据。

## 输入

- 1.2 的 `orders_clean.parquet`。

## 操作

1. 构造 SKU×月需求量面板：每个 SKU 每个月一行，没有订单的月份需求量为 0。
2. 按月份切分：训练期 2024-07～2025-12，验证期 2026-01～03，最终评估期 2026-04～06。

## 产物

- `outputs/panel.parquet`：SKU×月面板，带划分标记。
- `outputs/split_summary.json`：各划分的月份与行数。

## 验收标准

- 面板行数 = SKU 数 × 24 个月；面板需求量合计 = 清洗后非退货订单行的数量合计。
- 最终评估期在 7.1 最终模型之前不被任何步骤使用。

## 停止条件

- 需求量为 0 的 SKU 月超过 80% 时暂停：需要改为按类目预测或换模型形式。
