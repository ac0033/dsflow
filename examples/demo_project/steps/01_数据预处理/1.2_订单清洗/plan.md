# 1.2 订单清洗 · 计划

## 本步结束后要知道什么

清洗后的订单行能不能直接用来统计需求量：删了哪些行、为什么删、其余订单行的数量与金额是否原样保留。

## 输入

- `data/raw/orders.csv`（只读）；1.1 的 `quality_issues.json`。

## 操作

1. 删除完全重复行（所有字段都相同）。
2. 删除下单时间晚于数据截止月（2026-06）的未来日期行。
3. 商品名称统一全角 / 半角并去掉首尾空白。
4. 退货行（数量为负）、金额未知行只加标记列，不删除、不改数值。

## 产物

- `outputs/orders_clean.parquet`：清洗后订单明细，一行 = 一个订单行。
- `outputs/row_ledger.csv`：行数台账，每一步删了多少行。

## 验收标准

- 原始行数 − 删除行数 = 清洗后行数，台账数字可由平台重算。
- 平台对比原始与清洗后数据：除删除的行外，数量、金额两列统计量不变。

## 停止条件

- 删除行超过原始行数的 5% 时暂停，先查原因。
