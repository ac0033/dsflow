# 工业品商城月度需求预测（演示）

用模拟数据走通 DSFlow 的全流程：原始数据 → 盘点 → 清洗 → 需求分布探索 → 按时间切分 → 月度特征 → 基线 → 线性模型训练 → 预测 → 交付清单。数据是生成的，数字只用来演示平台，不代表任何真实业务。

## 一键运行

在仓库根目录：

```
uv run python examples/demo_project/scripts/run_all.py   # 约 1 分钟
uv run dsflow ui                                          # 打开平台
```

`run_all.py` 会：

1. 没有原始数据时先生成（`scripts/make_data.py`，固定随机种子，每次结果一致）；
2. 把本项目登记为可写（运行记录、模型登记写到 `.dsflow/`）；
3. 用 `dsflow run` 依次运行 8 个步骤的脚本，7.1 跑 4 组特征（3 次探索 + 1 次最终模型）；
4. 模型登记为 `sku_demand_linear`（候选），刷新交付清单的事实部分；
5. 最后跑一次交接前核对 `dsflow check`。

## 跑完会看到什么

| 步骤 | 结论 |
|---|---|
| 1.1 数据源盘点 | 订单明细 121,000 行；完全重复行 1,000、金额缺失 641、数量为负 364、未来日期 2 |
| 1.2 订单清洗 | 订单行 121,000 → 119,998；退货行 361、金额未知 636 只标记 |
| 2.1 需求分布探索 | 电力物资 12 月、MRO工业品 10 月、办公通用物资 3 月是高峰 |
| 3.1 按时间切分 | 3,000 个 SKU × 24 个月 = 72,000 行；训练期 54,000、验证期 9,000、最终评估期 9,000 |
| 4.1 月度特征 | 54,000 行，只用该月之前的需求量 |
| 6.1 基线模型 | 最好的基线：近 6 月均值，验证期 MAE 6.9544 |
| 7.1 线性模型训练 | 验证期 MAE 6.6481；最终评估期 6.6127（同期近 6 月均值基线 6.8679） |
| 11.1 交付与预测 | 2026-07 预测 3,000 个 SKU，按演示规则提示提前备货 42 个 |

各步都是「待验收」：说明卡（`step_card.yaml`）上的数字平台会从产物重算核对；模型的「已验收」「已交付」由你在「模型与交付」页确认并写明理由，脚本不替你决定。

## 目录

- `lifecycle/steps.json`：8 个步骤、依赖、执行脚本（`execution_scripts`）
- `src/demo_lib.py`：各步共用的特征与模型代码（训练和预测用同一套定义）
- `steps/…/src/*.py`：各步脚本；`steps/…/outputs/`：产物（不进仓库，由 `run_all.py` 生成）
- `delivery/sku_demand_linear/checklist.yaml`：交付清单
- `vocabulary.json`：术语表
